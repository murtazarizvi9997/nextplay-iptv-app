====================================================================
  NEXT PLAY IPTV — ANDROID MOBILE & ANDROID TV APP (XCIPTV STYLE)
====================================================================

Is project mein aapki complete Android Mobile + Android TV app shamil hai:
- Login screen par 3 options: 1) Username, 2) Password, 3) Server URL (default: https://nextplaytv.site)
- Login ke baad Full-Screen 3 Categories: LIVE TV | MOVIES | SERIES
- Live TV 3-Column XCIPTV Layout (Categories > Channels + Logos > Smooth Player)
- Movies & Series aapke server se LIVE auto-sync hoti hain (Series > Seasons > Episodes)
- Channel/Movie/Episode ke naam par click ya double-tap se Mobile aur Android TV par 100% Full Screen!
- Android TV Remote (D-Pad arrows + OK + Back button) full support!

--------------------------------------------------------------------
APK KAISE BANAYEIN (2 AASAN TARIKE):
--------------------------------------------------------------------

TARIKA 1 — BINA ANDROID STUDIO KE (FREE GITHUB CLOUD BUILD — 2 MINUTE):
1. GitHub.com par ek free private/public repository banayein.
2. Is ZIP ke andar ki saari files (including `.github/workflows/build-apk.yml`) upload kar dein.
3. GitHub par "Actions" tab kholein -> "Build NEXT PLAY IPTV APK" automatically chal jayega.
4. 2 minute baad "Artifacts" se `NextPlayIPTV-Mobile-TV-APK` download kar lein — uske andar ready-to-install `.apk` file hogi!

TARIKA 2 — ANDROID STUDIO (WINDOWS PC):
1. Android Studio open karein -> "Open" -> is extracted folder ko select karein.
2. Gradle sync complete hone dein.
3. Menu se Build -> Build Bundle(s) / APK(s) -> Build APK(s) par click karein.
4. Ready APK yahan milegi: `app/build/outputs/apk/debug/app-debug.apk`
